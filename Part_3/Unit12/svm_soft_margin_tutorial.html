① 鬆弛變數 (Slack Variable, ξ)

在現實中，資料很常混在一起。如果我們強制要求「街道上絕對不能有點」，這條線可能根本畫不出來。
因此我們允許點「違規」進入街道，甚至跨界。圖中 紅色線段 的長度，就是鬆弛變數 $\xi_i$。它計算了這個點距離它「本來應該在的安全邊界」有多遠。

軟邊界 SVM 目標函式

min ½‖w‖² + C × Σᵢ ξᵢ

s.t. yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ，ξᵢ ≥ 0

② 懲罰參數 (C) 的拔河遊戲

SVM 的優化目標是兩件事的拉扯：1. 街道越寬越好 vs 2. 違規成本 (C × Σξ) 越小越好。

  • 當 C 很大 (嚴格)： 犯錯的代價極高。模型寧可把街道縮得很窄，甚至把線歪掉，也要努力讓紅線 (ξ) 消失。（容易 Overfitting，被離群值牽著走）
  • 當 C 很小 (寬容)： 犯錯沒關係。模型會選擇畫出一條又寬又平穩的街道，允許幾個頑皮的點違規。（泛化能力較好，Robust）

💡 動手試試看： 點擊「模擬結果」按鈕，觀察面對離群值時，大 C 與小 C 的決策差異！或按 🎲 新資料 生成全新的資料集。
