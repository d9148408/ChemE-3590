💎 Lasso 回歸 (L1 正則化) 逐步互動教學

為什麼在最小平方法 (OLS) 加上「絕對值懲罰 $\alpha \sum |\beta_j|$」，就能讓模型具備自動把冗餘特徵係數砍成 0 的超能力？而圖上那一圈圈「誤差等高線」又是怎麼從數據點算出来的？透過以下 6 個循序漸進的互動實驗，從誤差等高線的誕生 (Step 0)、菱形尖角幾何、軟閾值死區、催化反應 8 特徵正則化路徑、尺度陷阱到共線性對決，徹底看懂 Lasso 回歸！

💡 核心機制對決 (L2 vs. L1)
🔵 Ridge 回歸 (L2)

懲罰平方和 $\sum \beta_j^2 \le t$（圓形平滑邊界），係數只會按比例漸近縮小，永遠不會剛好等於 0。

💎 Lasso 回歸 (L1)

懲罰絕對值和 $\sum |\beta_j| \le t$（菱形座標軸尖角），等高線極易撞上尖角，直接將冗餘係數歸零！

STEP 0 · 先備觀念解惑

「誤差等高線」到底是什麼？從擬合殘差、3D 誤差碗到 2D 地形圖！

👉 操作方式：拖曳下方 $\beta_1, \beta_2$ 滑桿 或 直接拖曳右圖的黃色探針點，並點擊「🔄 繞圈走一圈」觀察三張圖如何同步連動！
① 左圖：數據空間中的「殘差平方和 RSS」

每當你選定一組係數 $(\beta_1, \beta_2)$，模型就會畫出一條預測線 $\hat{y}_i = \beta_1 x_{i1} + \beta_2 x_{i2}$。每個真實數據點與預測線之間的紅色垂直距離平方加總，就是這組係數的總誤差 $\text{RSS}(\beta_1, \beta_2)$！

② 中圖：因為誤差取「平方」，立體圖是一個碗！

把橫軸設為 $\beta_1$、縱軸設為 $\beta_2$、高度 (Z 軸) 設為總誤差 RSS：因為誤差是二次方項 $\sum (y_i - \hat{y}_i)^2$，曲面向外呈拋物線上升，形成一個「3D 拋物面誤差碗」，碗底最低點就是 OLS 最佳解 $\hat{\boldsymbol{\beta}}^{\text{OLS}}$！

③ 右圖：把 3D 誤差碗「水平切開」向下投影！

就像地理課的山谷等高線地形圖：拿一把水平刀在固定誤差高度（例如 $\text{RSS} = 18, 30, 45$）把 3D 碗切開，切出來的橢圓形截面投影到 2D $(\beta_1, \beta_2)$ 平面，就是誤差等高線！同一圈上所有點的誤差完全相同。

❓ 常見疑問 1：為什麼等高線是「橢圓形」而不是正圓形？而且還會傾斜？

展開誤差平方和公式可得二次型： $$\text{RSS}(\boldsymbol{\beta}) = \text{RSS}_{\min} + (\boldsymbol{\beta} - \hat{\boldsymbol{\beta}}^{\text{OLS}})^T (\mathbf{X}^T \mathbf{X}) (\boldsymbol{\beta} - \hat{\boldsymbol{\beta}}^{\text{OLS}})$$ 因為不同特徵對誤差的敏感度（特徵值）不同，所以一個方向碗壁比較陡、另一個方向比較緩，切出來就是橢圓；而當兩個特徵 $X_1, X_2$ 之間有相關性（$\mathbf{X}^T\mathbf{X}$ 非對角線元素不為 0）時，橢圓就會斜向旋轉！

❓ 常見疑問 2：理解了誤差等高線，那跟 Step 1 的 Lasso 菱形有什麼關係？

在 Lasso 回歸中，我們的係數被限制不能超出綠色菱形 $|\beta_1|+|\beta_2| \le t$（而紅星碗底 $\hat{\boldsymbol{\beta}}^{\text{OLS}}$ 在菱形外面，進不去！）。我們想在菱形內部找一個誤差 RSS 最小（也就是離碗底紅星最近、所在等高線圈數最小）的點——想像把等高線從紅星像水波一樣一圈一圈往外放大，第一圈碰到綠色菱形的那個切點，就是菱形內誤差最小的 Lasso 最佳解！

🧠 為什麼「菱形尖角」能做到特徵選擇？

1. 等高線代表預測誤差 (RSS)：以紅星 $\hat{\boldsymbol{\beta}}^{\text{OLS}}$ 為中心，越往外圈誤差越大。我們要在約束區域（綠菱形或藍圓）內找離紅星最近的一點（即第一個相交的切點）。

2. Ridge (L2 圓形) 處處平滑：圓周上沒有尖角，切點幾乎永遠落在象限內部 ($\beta_1 \neq 0, \beta_2 \neq 0$)，所以 Ridge 只能把係數縮小，無法剔除特徵。

3. Lasso (L1 菱形) 在座標軸上有突出尖角：在 2D 中是菱形 $( \pm t, 0 ), ( 0, \pm t )$，在高維空間則是超正八面體 (Cross-polytope)。向外擴張的橢圓極容易直接撞在座標軸尖角上，一旦撞上尖角，該軸以外的座標就嚴格等於 0！

STEP 2

數學引擎解剖：軟閾值算子 (Soft-Thresholding) 如何把微弱係數「一刀歸零」？

👉 操作方式：調整未正則化估計值 $z_j$ 與正則化門檻 $\alpha$，觀察左圖的「歸零死區 $[-\alpha, +\alpha]$」與右圖的目標函數尖底！
📐 座標下降法 (Coordinate Descent) 核心更新公式：軟閾值函數
$$\hat{\beta}_j^{\text{Lasso}} = \text{soft}(z_j, \alpha) = \begin{cases} z_j - \alpha & \text{if } z_j > \alpha \quad (\text{正係數向零平移收縮 } \alpha) \\ 0 & \text{if } |z_j| \le \alpha \quad (\text{落入死區，直接砍為 } 0\text{！}) \\ z_j + \alpha & \text{if } z_j < -\alpha \quad (\text{負係數向零平移收縮 } \alpha) \end{cases}$$
🔍 對比 Ridge (L2) 的比例收縮公式
$$\hat{\beta}_j^{\text{Ridge}} = \frac{z_j}{1 + \alpha}$$

無論 $\alpha$ 多大，只要原始相關性 $z_j \neq 0$，Ridge 除以 $(1+\alpha)$ 後永遠不為 0；而 Lasso 是減去固定門檻 $\alpha$，小於 $\alpha$ 的噪音特徵直接歸零！

STEP 4

關鍵前提實驗：如果不做特徵標準化，Lasso 會發生什麼災難？

👉 操作方式：切換「❌ 未標準化（原始物理單位）」與「✅ Z-score 標準化後」，並改變催化劑單位（wt% $\rightarrow$ ppm）觀察不公平懲罰現象！
⚠️ 為什麼 Lasso 與 Ridge 強制要求先做 `StandardScaler` 標準化？

Lasso 的懲罰項 $\alpha \sum_{j=1}^p |\beta_j|$ 對所有係數的絕對值一視同仁。但在化工製程中，不同感測器量綱差異極大：若把某個特徵的單位縮小 1000 倍（例如從 $\text{bar}$ 改為 $\text{kPa}$，或從 $\text{wt\%}$ 改為 $\text{ppm}$），它的數值 $X_j$ 會放大 1000 倍，導致對應的回歸係數 $\beta_j$ 自動縮小 1000 倍！如果未標準化，單位量綱較小（係數數值較大）的重要特徵，反而會被 Lasso 當成罪犯優先砍成 0！

① 選擇前處理模式 (Preprocessing Mode)
② 單位換算實驗：改變「催化劑濃度」的紀錄單位
③ 正則化強度 $\alpha$ α = 0.80
$\alpha=0$ (OLS) 拖曳觀察誰先被歸零 $\alpha=2.5$
❌ 未標準化模式：各特徵占真值比例 ($\hat{\beta}_j / \hat{\beta}_j^{\text{OLS}}$) — 數值範圍小的特徵慘遭優先砍除！

STEP 5

進階限制實驗：當兩個感測器高度共線性 ($r \to 1$) 時，Lasso 會怎麼做？

👉 操作方式：拖曳兩支溫度感測器的相關係數 $r$ 與抽樣批次種子，對比 OLS、Ridge、Lasso 與 Elastic Net 的係數分配行為！

在實際化工廠中，同一座反應器常安裝多支位置相近的溫度感測器，它們的讀數高度正相關（多重共線性 Multicollinearity，$r \approx 0.95$），且對產率的真實總貢獻為 $\beta_1 + \beta_2 = 6.0$（各自真實貢獻皆為 $3.0$）。讓我們看看四種回歸模型面對共線性時的截然不同表現！

2. Ridge (L2)：自動均分權重（Grouping Effect） (+2.85, +2.83)

因為平方和 $(3^2+3^2=18) < (6^2+0^2=36)$，L2 懲罰天然偏好把權重平均分配給共線的重要特徵，非常穩定！

3. Lasso (L1)：霸道二選一，另一個直接砍為 0 (+5.65, 0.00)

因為 $|6|+|0| = |3|+|3| = 6$，L1 對均分毫無偏好！當等高線拉長時會隨機撞上其中一軸尖角，任意保留一個、剔除另一個（換個抽樣批次可能就選另一支溫度計）。

4. Elastic Net (L1 + L2 結合)：兩全其美 (+2.78, +2.72)

同時加入 L1 與 L2 懲罰，既能像 Lasso 一樣剔除無關冗餘特徵，又能像 Ridge 一樣將共線的重要特徵成組保留（下一單元 Unit 10 Elastic Net 主角！）。
